# minecraft-web
Minecraft (Web Edition) Three.js gücüyle tarayıcıya taşınan voxel dünyası. Seed tabanlı biyom üretimi, dinamik envanter sistemi ve akıcı 3D render kapasitesiyle blok evrenini doğrudan web'e getirir. Saf JavaScript ile inşa edilmiş, yüksek performanslı ve optimize bir sandbox deneyimi.
